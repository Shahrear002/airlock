# Customization & Themes

Airlock provides robust customization options so you can tailor the interface and terminal to match your preferred workflow and aesthetic.

## App Themes

Airlock supports application-wide themes that change the look and feel of the user interface.

- **Default Theme**: A clean, high-contrast light/dark mode UI designed for maximum readability.
- **Glassmorphism Theme**: A premium, modern dark mode featuring deep `#0A0D14` backgrounds, vibrant gradients, frosted glass panels, and floating inputs.

To change your app theme:
1. Click the **Settings (gear icon)** at the bottom of the sidebar.
2. Under the **Appearance** section, select your preferred theme from the **App Theme** dropdown.
3. The interface will update instantly.

## Terminal Themes

You can customize the color palette of your SSH terminal independently of the app theme. Airlock comes bundled with several popular terminal themes:
- Dracula
- One Dark
- Monokai
- Campbell (Windows Command Prompt style)

To change the terminal theme:
1. Open **Settings**.
2. Select a theme from the **Terminal** dropdown menu.

### Importing Custom Terminal Themes

If your favorite color scheme isn't included, you can import custom JSON theme files:
1. In **Settings**, click the **+ (Import Theme)** button next to the Terminal dropdown.
2. Select a valid JSON theme file from your computer.
3. The theme will be permanently saved to your configuration and become available in the dropdown menu.

## Workspace Layout

- **Resizable Sidebar**: Drag the edge of the sidebar to adjust its width, giving your terminal more or less space as needed.
- **Collapsible Sidebar**: Click the Explorer toggle at the top of the sidebar to completely collapse it, maximizing your terminal real estate.
- **Split Screen**: Right-click inside any active terminal to split the view horizontally or vertically for multi-tasking.
